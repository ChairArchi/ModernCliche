# MODERN CLICHÉ · Depth & Shape Research 2.1

**대상 검색 → 이미지 검토 → 형상·깊이 분석 → Sorting과 규칙 탐색 → 3D 표면 생성**

수집한 이미지의 실루엣과 추정 깊이를 함께 분석하는 Python 연구 도구입니다. 깊이 모델의 추론, 카메라 좌표 복원, 메시 생성, 실험 기록 저장을 앱 내부에서 실행합니다.

## 실행

Python **3.11 또는 3.12**를 사용하십시오.

```bash
python -m pip install -r requirements.txt
python -m streamlit run streamlit_app.py
```

MoGe-2와 Depth Anything V2를 기본 설치에 포함합니다. Linux CPU용 PyTorch 인덱스를 함께 사용하며 CUDA가 있는 환경에서는 추론 장치를 자동 선택합니다. GPU용 PyTorch가 필요하면 해당 장치에 맞는 PyTorch 빌드를 설치하십시오. 사전 학습 가중치는 첫 추론에서 다운로드합니다. 추론 결과는 이미지·마스크·모델 버전·설정을 기준으로 재사용합니다.

Streamlit Community Cloud의 진입점은 `ChairArchi/ModernCliche` → `main` → `streamlit_app.py`입니다. 기본 Base 모델과 다수 이미지의 깊이 배열은 메모리를 사용하므로, 메모리가 제한된 환경에서는 Small 모델과 384/512 해상도를 선택하십시오. 클라우드 서비스의 자원 한도 내 실행은 별도 확인이 필요합니다.

## 사용 흐름

1. 검색하거나 사진을 업로드합니다. 검색 결과의 실제 대상, 출처, 촬영 방향을 검토합니다.
2. 대상 영역을 추출하고 주황 영역을 확인합니다. 잘못 추출된 자료는 제외하거나 같은 크기의 수정 마스크 PNG를 적용합니다. 사람·여러 동물·회화가 섞인 검색 결과는 별도로 검토해야 합니다.
3. **깊이 특징을 분류와 규칙 분석에 포함**한 상태로 분석합니다. 형상 통계와 깊이 범위·기울기·불연속 등을 함께 비교하고, 그룹별 대표 이미지 및 측정 차이를 확인합니다.
4. **이미지 깊이 기반 표면**에서 관측 이미지를 선택합니다. 깊이 맵, 원본, 무채색 기하 형태, 원본 색상 메시를 비교합니다. 가림 경계의 연결 기준과 메시 해상도를 조정할 수 있습니다.
5. GLB·PLY·OBJ·STL 또는 실험 ZIP을 저장합니다. GLB와 PLY에는 원본에서 가져온 정점 색상이 포함됩니다. STL은 색상을 포함하지 않습니다.

최소 3장, 비교에는 20장 이상을 권장합니다. 표본의 방향·자세 차이도 특징 차이에 포함됩니다. 불안정한 분류를 의미 있는 그룹으로 강제하지 않습니다. 기존 라벨은 `filename,label` CSV로 보존할 수 있습니다.

## 깊이 모델과 3D 구성

| 선택 | 이미지에서 얻는 정보 | 해석 범위 |
|---|---|---|
| **MoGe-2 Base · 기본** | 깊이, 3D 좌표, 추정 카메라 내부 파라미터 | 보이는 표면의 단안 추정. 모델의 미터 척도는 실측 검증되지 않았으며 제작 크기는 사용자가 지정합니다. |
| MoGe-2 Small / Large | 같은 종류의 좌표 및 카메라 추정 | Small은 자원 사용을 줄이는 선택입니다. Large는 비교 옵션이며 이 프로젝트에서 실제 Large 추론은 검증하지 않았습니다. |
| Depth Anything V2 Small | 상대 역깊이 | 카메라와 역깊이 오프셋을 가정하는 비교 경로입니다. 보정된 실제 거리로 해석할 수 없습니다. |
| 실루엣 통계 변형 | 거리장 PCA 또는 평균 보간 | 기존 반경 가정 경로입니다. 추정 깊이를 사용하는 경로와 명확히 구분됩니다. |

새 메시 경로는 이미지 내부에서 예측된 좌표를 직접 삼각형으로 연결합니다. 실루엣 내부를 타원체로 부풀리지 않습니다. 급격한 깊이 차이에는 삼각형을 만들지 않아 가려진 면을 가로지르는 연결을 줄입니다. 모델 추론 실패 시 기존 반경 가정으로 자동 대체하지 않습니다.

**한 장의 사진은 보이지 않는 뒷면을 제공하지 않습니다.** 기본 출력은 열린 표면입니다. 추가 두께를 지정하면 보이는 표면을 깊이 방향으로 평행 이동한 닫힌 셸을 생성합니다. 이는 관측되지 않은 면의 복원이 아니라 제작용 가정입니다. 닫힌 표면이어도 분리된 부품이나 자기 교차가 있을 수 있습니다.

서로 다른 개체의 사진을 합쳐 특정 개체의 360° 형상을 복원하지 않습니다. 완전한 대상 복원에는 같은 개체의 여러 각도 사진과 카메라 정합이 필요합니다. 단안 추정에서 해부학적으로 정확한 전체 입체를 보장하지 않습니다.

## 명령줄과 재현

```bash
python -m modern_cliche.cli --query gargoyle --limit 24 --output output/gargoyle
python -m modern_cliche.cli --input ./images --depth-model moge-base --output output/local
python -m modern_cliche.cli --input ./images --depth-model moge-small --depth-resolution 512 --detail 6 --output output/cpu
python -m modern_cliche.cli --experiment experiment.zip --output output/reproduced
```

기본 CLI는 관측 대표 이미지의 깊이 표면을 생성합니다. 전체 깊이 특징도 분류에 포함됩니다. 이전 실루엣 변형 실험에는 `--geometry silhouette --mode variation --sigma 1.0`을 명시하십시오. 자동 마스크 검토 플래그는 기본적으로 제외합니다.

ZIP에는 원본, 마스크, 출처, 제외 기록, 분석 특징, PCA, 모델 ID와 고정된 가중치 리비전, 깊이·좌표 NPZ, 생성 설정과 메시가 포함됩니다. CLI는 저장된 배열을 사용해 오프라인으로 재현합니다. 앱 복원에서는 이전 모델과 해상도 설정을 맞추면 저장된 깊이를 재사용합니다. 패키지 버전을 맞춰 수치 결과를 비교하십시오. 2.0의 실루엣 ZIP도 복원할 수 있습니다.

## 연구 범위와 검증
